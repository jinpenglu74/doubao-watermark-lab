# 水印清理工作台后续开发计划

## 当前重点问题

实际测试发现，部分图片仍存在去水印遗漏：

- 半透明水印
- 低对比文字水印
- 复杂背景融合水印
- 非固定位置水印
- 多处重复水印
- Logo/署名类水印

不能针对单一截图修复，需要升级为通用残留检测能力。

## 下一阶段开发路线

### 1. 全图残留检测引擎升级

目标：从规则检测升级为多特征融合检测。

检测维度：

- OCR文字候选区域
- 边缘连续异常纹理
- 半透明叠加区域
- 高频重复纹理
- Logo形状特征
- 图像语义异常区域

统一输出：

```json
{
  "region": {"x":0,"y":0,"width":0,"height":0},
  "confidence": 0.0,
  "type": "text/logo/pattern"
}
```

### 2. 自适应补修流程

- 高置信区域自动生成遮罩。
- 局部重绘后重新检测。
- 最多多轮修复。
- 中低置信区域保留人工确认。

避免：

- 漏删水印
- 误删图片原有文字

### 3. 豆包会话效率优化

当前方向：

- 不再简单固定“一张图片一个对话框”。
- 根据人物主体、图片相似度、连续任务数量动态复用会话。
- 平衡速度和上下文污染。

建议策略：

- 同主体图片批量复用会话。
- 超过阈值自动刷新上下文。
- 异常任务独立隔离。

### 4. 测试覆盖

建立标准测试集：

- 角落水印
- 中间水印
- 半透明水印
- 平铺水印
- 旋转水印
- 多语言水印
- 多尺寸图片
- 复杂人物背景

验收标准：

不是解决当前图片，而是形成通用水印清理能力。
